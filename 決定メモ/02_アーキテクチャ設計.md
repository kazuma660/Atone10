# アーキテクチャ設計

## ディレクトリ構造

```
Atone10%/
  企画案/               ← 仕様書（触らない）
  決定メモ/             ← 本フォルダ（決定事項の記録）
  public/
    audio/             ← BGM・SE ファイル（.mp3 / .ogg）
  src/
    App.jsx            ← ルートコンポーネント：GameCanvas + HUD を合成
    components/
      HUD.jsx          ← バッテリー数値・フロア表示（Canvas の上に絶対配置）
    game/
      GameCanvas.jsx   ← Canvas 要素 + requestAnimationFrame ループの起点
      gameLoop.js      ← update() / draw() を束ねるコアループ
      entities/
        Player.js      ← 位置・速度・ライト状態・ケーブル所持フラグ
        Ghost.js       ← 幽霊の出現ロジック・freeze 判定
      levels/
        floor4.js      ← 廊下レイアウト（壁 AABB・デブリ・階段座標）
        floor3.js
        floor2.js
        floor1.js      ← 配電盤座標・ケーブル配置
      systems/
        battery.js     ← バッテリー消費・クランプ・オーバーフロー演出
        collision.js   ← 壁・デブリ衝突判定（AABB）
        camera.js      ← lerp 補間カメラ追尾
        audio.js       ← AudioContext ベースの SE / BGM 管理
      effects/
        noise.js       ← 灰・ノイズオーバーレイ
        flicker.js     ← ライトちらつき（Math.random ノイズ）
        heartbeat.js   ← バッテリー≤3% 時の画面パルス
    index.css
    main.jsx
  vite.config.js
  vercel.json
  package.json
```

## データフロー

```
キー入力（keydown/keyup）
  └─→ Player.js（位置・速度を更新）
        └─→ collision.js（壁との衝突解決）
        └─→ battery.js（消費量計算）
              └─→ HUD.jsx（React state 経由でバッテリー数値を表示）

gameLoop.js（requestAnimationFrame）
  └─→ update()
  │     Player, Ghost, battery, camera を毎フレーム更新
  └─→ draw()
        Canvas に廊下・プレイヤー・ライト・幽霊・エフェクトを描画
```

## React と Canvas の分離方針
- **Canvas**：ゲーム描画（廊下・プレイヤー・エフェクト）
- **React DOM**：HUD のみ（`position: absolute` で Canvas 上に重ねる）
- ゲーム状態は `useRef` で保持し、HUD 表示に必要な値のみ `useState` で React に渡す
