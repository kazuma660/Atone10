# 開発依頼：ホラーゲーム『Atone: 10%』基盤実装

## 1. 概要
- **Framework:** React + Canvas API
- **ビジョン:** 20年前、少女を置き去りにした廃団地を舞台にした、心理的没入感重視のホラー。
- **目標:** 4F（崩壊した精神）から1F（事件現場）へ下り、真実を清算する。

## 2. 没入感（Immersion）実装指示
単なる2Dゲームではなく、以下の「手触り」をコードで再現してください。
- **ライトの揺らぎ:** 扇状のライトの範囲を、常に微細なノイズ（`Math.random()`）で震えさせてください。「震える手でスマホを握る」感覚を再現します。
- **Lerpカメラ:** プレイヤーの移動に対し、Canvasの視点がわずかに遅れて追従する（線形補間）ことで、浮遊感と不安感を演出してください。
- **画面の汚れ:** Canvas全体に薄く、静止していない「煤（すす）」や「ノイズ」のオーバーレイをかけ、廃墟の空気感を表現してください。

## 3. コア・ロジック
- **バッテリー:** 10.0%固定。10.1%以上への回復試行時は、激しい画面の揺れ（Screen Shake）と共に10.0%へクランプしてください。
- **暗闇ペナルティ:** ライトOFF時は、恐怖による硬直を表現するため移動速度を50%に低下させてください。
