# 企画仕様書：Atone: 10%

## 1. ストーリー：『20年目の決着』
20年前の肝試し。あなたは恐怖に負け、一人の少女の手を離して逃げ出した。
今、その廃団地はあなたの罪を具現化した迷宮となっている。
スマホに残された10%のバッテリーは、彼女の怨念が許した「最後の対話時間」である。

## 2. 階層設計：『深淵から真実への下降』
- **4F (Start):** 20年の風化が最も激しい階。植物が侵食し、壁が崩落している。
- **3F-2F:** 徐々に「あの日」の記憶が混じり始める。古い玩具や、当時の規制線が道を塞ぐ。
- **1F (Goal):** 事件が起きたロビー。ボロボロだが、配置だけは20年前のままで時間が止まっている。

## 3. 真エンド：救済の自爆
1Fの配電盤に「高電圧ケーブル」を接続。10%という欺瞞の数値を自爆によって突き破り、強烈な閃光で少女を救済すると同時に、自らの過去を焼き払う。
